# Nomadic – Personalized Travel Website

## 1. Project Title
**Nomadic – Personalized Travel**

A personalized travel website that helps users explore destinations, discover travel packages and manage their travel bookings.

## 2. Problem Statement
Planning a trip involves searching multiple websites for destinations, packages, prices and travel information. This can make the planning process time-consuming and complicated.

Nomadic aims to provide a centralized platform where users can explore destinations, discover suitable travel packages and manage their bookings.

## 3. Objectives
- Develop a user-friendly travel website.
- Provide destination and travel package information.
- Implement user registration and login.
- Allow users to search and explore travel packages.
- Enable users to submit and manage bookings.
- Store application data in a SQL Server database.
- Provide a responsive interface for different devices.

## 5. Installation and Execution Steps

1. Clone the repository:

   `git clone https://github.com/jeetsojitra/Nomadic-Personalized-Travel.git`

2. Open the project folder in Visual Studio or VS Code.

3. Configure the SQL Server connection string in `appsettings.json`.

4. Open the terminal in the project directory.

5. Restore dependencies:

   `dotnet restore`

6. Apply database migrations if required:

   `dotnet ef database update`

7. Run the application:

   `dotnet run`

8. Open the localhost URL displayed in the terminal.
